# moderation-keywords-extended

## Français

Liste noire de mots et expressions offensants en français et en anglais.  
Générée avec variantes d’accents, leetspeak, casse.  

**Fichiers :**
- `blacklist.txt` : liste originale  
- `blacklist.json` : format JSON  

Usage : modération, filtrage, détection de langage toxique.  
Contient des termes offensants — à utiliser uniquement pour la modération automatique.

## English

Blacklist of offensive words and phrases in French and English.  
Generated with accented, leetspeak, case.  

**Files:**

Use for moderation, filtering, or toxicity detection only.
